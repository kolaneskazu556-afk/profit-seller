# Профит селлера: прибыль по артикулам WB и Ozon

Загрузка отчётов площадок и таблицы себестоимости → прибыль по артикулам, поиск убыточных, ориентировочные налоги, выплаты, демо, чат (GigaChat), PDF.
Рабочее название: придумайте своё (идеи: ПрофитСеллер, МаржаПро, ЧистаяМаржа; доступность доменов .ru НЕ проверялась).

## Статус проверки
- **Проверено тестами** (`python -m unittest discover -s tests -v`, 15 тестов): разбор синтетических отчётов WB (xlsx/csv) и Ozon (xlsx/json), расчёт прибыли сверен с эталоном `sample_data/ground_truth_synthetic.csv`, налоги, грязные данные, сверка выплат, PDF.
- **Не проверено**: запуск веб-слоя (`app.py`, `index.html`) в браузере, GigaChat, `setup.sh` на сервере. Первый запуск смотрите по `/ping`.
- **Главное допущение**: колонки и типы операций заложены по синтетическим примерам. Реальные отчёты WB/Ozon нужно прогнать до запуска: если формат отличается, правятся словари `WB_ALIASES`, `OZ_ALIASES`, `oz_bucket_text` в `core.py`. Сервис сам сообщит, какие колонки не нашёл.

## Локальный запуск
```
pip install -r requirements.txt
uvicorn app:app --reload        # http://127.0.0.1:8000, кнопка «Демо» работает без файлов
python -m unittest discover -s tests -v
```
Для PDF нужен шрифт DejaVu (на Windows подхватывается из C:/Windows/Fonts, если установлен; на Ubuntu пакет `fonts-dejavu-core`).

## Развёртывание (REG.RU, Ubuntu 24.04)
См. шапку `setup.sh`. Обновление: `sudo bash /opt/wbozon/deploy/update.sh`.

## Структура
`core.py` разбор и расчёт · `app.py` API и SQLite · `index.html` интерфейс · `llm.py` GigaChat · `report_pdf.py` PDF ·
`synthetic.py` генератор тестовых данных · `sample_data/` готовые синтетические отчёты · `deploy/` бэкап и обновление.

## Налоги (проверено по открытым источникам 05.11.2026, сверяйте с ФНС)
УСН 6% / 15% (регионы могут снижать), НПД 4%/6% (только товары собственного производства, лимит 2,4 млн ₽), на УСН НДС при доходе свыше 20 млн ₽ (5% / 7% / 22%) НЕ рассчитывается. Взносы и вычеты не учитываются.
